# Painel CVD

Página do painel financeiro (Início e Comercial), publicada no GitHub Pages.

Os dados vêm do Supabase por `public.painel_comercial()`, que exige login e só responde para
e-mails da lista `public.painel_acessos`. Este repositório não contém dados nem chaves secretas
(a chave do Supabase aqui é a pública "anon").

Design: design system C3D (o mesmo de operacao.3cvd.com.br).
